# Reference copies (read-only)

Files uploaded from Dan's PC so the inspection app could copy their look and patterns.
Nothing here runs or deploys; the live apps are on Dan's PC and their own repos.

- `craigapp/`: the Indeca Ticket Log (CraigApp). The web upload flattened its folders, so files
  that shared a name were renamed (`page (9).tsx` is People, `page (10).tsx` My log,
  `page (11).tsx` Driver home, `page (12).tsx` Sheet, `page (13).tsx` Sign in, `page.tsx` Dispatch).
- `onetrip/`: the OneTrip pre-trip inspection system (driver app, Drive function, admin dashboard,
  mechanic portal) and its `PROGRESS.md` history.
